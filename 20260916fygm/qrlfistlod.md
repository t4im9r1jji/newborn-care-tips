# 佛山市医学会儿科分会年会暨广东省儿科常见病规范诊疗及新进展研讨会”顺利举行

> 更新时间：2026-09-16 (UTC+8)

由佛山市医学会儿科分会主办，佛山市妇幼保健院、南海区第七人民医院联合承办的“佛山市医学会儿科分会2019年年会暨广东省儿科常见病规范诊疗及新进展研讨会”7月底在佛山市隆重召开，我市各区镇200余名儿科同行参加了本次年会。
本次年会邀请多位省内外知名专家莅临授课，包括呼吸系统、神经系统、内分泌系统、感染性疾病等领域的新动态、新进展和新技术等。11场精彩专题授课为同行传道授业、释疑解惑。

佛山市妇幼保健院高平明副院长在开幕式上致辞

**1******

来自广州妇女儿童中心徐翼教授就“儿童EB病毒感染的诊断与治疗”进行了专题讲座，主要介绍了EB病毒感染相关疾病诊断，包括传染性单核细胞增多症、噬血细胞综合征、慢性活动性EBV感染，以及EB病毒相关感染的规范治疗，其深入浅出的讲解使参会学员受益匪浅。

**2******

南方医科大学附属珠江医院李宏教授就“生物节律与癫痫发作”专题进行了讲授，介绍了癫痫发作的生物节律特征及可能机制，为癫痫诊断及治疗从生物节律方面提供了新的思路。

**3******

上海儿童医学中心儿童呼吸及肺功能领军人物张皓教授就“以小气道病变为主的哮喘治疗”专题进行了讲授，对小气道病变在哮喘中的角色及以小气道病变为主哮喘的治疗进行生动的讲解，让学员们对小气道病变为主的哮喘有了更深入的理解。

**4******

广州医科大学第一附属医院过敏原研究及肺免疫监测专家孙宝清教授为我们就“过敏原检测在过敏性疾病诊治中的重要意义”进行专题讲座，主要介绍了临床过敏原检测的常用方法，并介绍了关于食物过敏组分检测的前沿进展。

**5******

中山大学第一附属医院的儿童内分泌专家张军教授就“儿童矮身材的诊断”进行了专题讲座，具体讲授了关于儿童矮身材相关常见病、罕见病的诊疗。

**6******

中山大学第一附属医院的儿童内分泌专家李燕虹教授分别就“中枢性性早熟的诊治”进行了专题讲座，对中枢性性早熟诊断思路及规范诊疗进行了细致的讲解；学员们受益匪浅。

**7******

广州市妇女儿童医疗中心的江文辉教授讲授了“小儿腺病毒肺炎的诊治进展”，具体讲述腺病毒肺炎的临床表现、重症腺病毒肺炎的早期识别、治疗策略等，为基础医院腺病毒肺炎的诊疗提供了很大帮助，激起了学员们高涨的学习讨论热情。

**8******

广州市妇女儿童医疗中心的温秀兰主任护师就“以家庭为中心护理服务模式在儿童慢病护理中的应用”进行专题讲座，为护理人员进行儿童慢性疾病的家庭延续护理提供了参考。

**9******

来自佛山市第一人民医院儿科主任麦智广教授，就“疫苗接种的知情沟通与纠纷防范”进行幽默风趣的授课，指导全市儿科医师合理、规范的使用疫苗。

**10******

佛山市妇幼保健院儿科主任刘志刚教授进行“癫痫患儿基因检测汇报”，就近一年来在癫痫基因诊断方面的临床经验进行总结，从基因检测在癫痫病因诊断、治疗选择、遗传咨询中的应用，及临床工作中对癫痫患儿基因检测的新发现等进行授课；使学员对癫痫的基因检测有了一定的认识。

**11******

南方医科大学新生儿科主任黄为民教授进行“aEEG在NICU的临床应用”的专题讲座，就aEEG在监测惊厥发作、早产儿脑损伤、代谢性疾病引起的脑损伤、颅内感染、先天性大脑发育畸形等方面临床应用进行授课；使学员们对aEEG的应用有了更全面的认识。

学员们纷纷表示，各位专家的讲课开阔眼界，相关领域的临床思维得到了系统的提高，切实有效帮助到自己在临床中相关疾病的识别与治疗。

近年来，我院积极举办各类学术交流活动，与国际、国内众多权威医疗机构、知名专家进行广泛的学术交流，以海纳百川的姿态吸纳百家精华，以进取的精神推进医学创新。此次年会不仅展示了我市儿科的专业特色和实力，而且进一步推进了本地区儿科学的蓬勃发展。
